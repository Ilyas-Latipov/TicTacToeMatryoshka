Main
The game is similar to the board game Gobblet Gobblers, which is a more complex version of tic-tac-toe. The game is designed for 2 players. The game does not require an internet connection. You can choose a theme for the game (light or dark). This game will make even adults think.
Comparisons of this game with regular tic-tac-toe:
The number of possible games in tic-tac-toe is approximately 5700;
The number of possible games in this game is ~1.3 billion;

Rules:
The player who builds a row or diagonal of 3 pieces of his color wins. Large pieces can cover smaller ones. The player can move his pieces to adjacent squares (by clicking on a piece of his color). Reds move first. Players have a limited number of pieces of each size (3 by default). Until the player has placed a piece on the field, the move can be canceled.
